Little Lemon REST API Endpoints

This backend application powers web & mobile clients through Django REST Framework and token authentication.

GET /restaurant/menu/ Retrieve all menu items
POST /restaurant/menu/ Create new menu item
GET /restaurant/booking/tables/ Retrieve bookings (Token required)
POST /auth/users/ User registration
POST /api-token-auth/ Generate authentication token
